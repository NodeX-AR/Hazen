# Contributing

Thanks for helping. Hazen is **not open source**: see [LICENSE](LICENSE). You may not fork-and-redistribute modified copies, but you are welcome to help improve the official app.

## Good ways to help
- Report bugs and device-specific problems ([issue form](https://github.com/NodeX-AR/hazen/issues/new/choose)).
- Suggest features.
- Send small, focused pull requests (bug fixes, docs, translations).

## Pull requests
1. Open an issue first for anything bigger than a small fix.
2. Keep one change per PR and fill in the PR template.
3. Test on a real phone when you touch the camera, editor or recording.
4. `demo.html` has no build step; run `node` syntax check as in `ci.yml`.

## Legal
By sending a contribution you agree to section 4 of the [LICENSE](LICENSE): the copyright holder may use, modify and distribute it as part of Hazen. Only send work you have the right to share.
