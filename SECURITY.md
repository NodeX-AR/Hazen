# Security Policy

## Supported versions
Only the latest release receives security fixes.

## Reporting a vulnerability
Please do **not** open a public issue.
- Use GitHub: **Security > Report a vulnerability** (private advisory), or
- email aswanthr82@gmail.com with steps to reproduce, affected platform and version.

We aim to acknowledge within 3 working days and to ship a fix or mitigation for confirmed issues within 30 days. Please give us time to fix before disclosing publicly. Good-faith research that does not access other people's data is welcome.

## Scope
In scope: the app code, the wrappers (Android, iOS, desktop), the release workflows and the website. Out of scope: third-party services (jsDelivr, Google model storage) and issues needing a rooted or already-compromised device.

## Privacy by design
Photos and videos stay on the device; there is no server and no account. See `store/privacy-policy.md`.
